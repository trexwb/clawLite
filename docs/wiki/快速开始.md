# 快速开始

## 一、终端用户：安装与使用

1. 下载安装包：`Claw-Lite-<版本>-arm64.dmg`（Apple Silicon）或 `Claw-Lite-Setup-<版本>.exe`（Windows），见 [Releases](https://github.com/trexwb/clawLite/releases)。
2. 打开 dmg，**把 Claw Lite 拖入「应用程序」文件夹** —— 不要直接从磁盘映像里双击运行。
3. 首次打开若提示「无法验证开发者」：右键点击应用图标 → 选择「打开」→ 确认。
4. 在主控制面板点击「启动」，等待状态变为运行中，访问地址会自动回填（含 dsh Web UI 的信任 token）。
5. 点「打开界面」在应用内窗口打开 dsh web，或用「复制」把地址贴到系统浏览器。

> **macOS 限制**：应用从 DMG 只读卷直接运行时，系统不允许其拉起内置运行时。应用已内置检测，遇到这种情况会主动提示并引导完成拖入步骤。
>
> **仍无法打开 / 想一步解除 Gatekeeper 拦截**：在「终端」执行下面命令移除下载隔离标记，再从「应用程序」重新打开：
>
> ```bash
> xattr -dr com.apple.quarantine "/Applications/Claw Lite.app"
> ```
>
> 该命令仅清除系统给应用打的隔离属性，不修改应用内容；路径需与实际安装包名一致。

## 二、开发者：从源码运行

前置要求：**Node ≥ 24**（仅开发需要——`scripts/*.ts` 依赖 node 原生类型擦除直跑；终端用户无需任何环境）。

```bash
npm install            # 安装依赖
npm run runtime        # 拉取内置 DSH 依赖树到 resources/dsh（约 300MB，首次必需）
npm start              # 构建主进程 + 渲染层，然后启动应用
```

开发模式（渲染层热更新，端口固定 5173）：

```bash
npm run dev            # Vite dev server
CLAWLITE_DEV_SERVER=http://localhost:5173 npm run electron
```

## 三、常用脚本

| 命令 | 作用 |
|---|---|
| `npm run build` | 构建主进程（esbuild → `dist-electron/`）+ 渲染层（Vite → `dist/`） |
| `npm run build:electron` | 只构建主进程产物 |
| `npm run build:web` | 只构建渲染层产物 |
| `npm run runtime` / `runtime:force` | 拉取 / 强制刷新内置 DSH 依赖树 |
| `npm run check` | 静态自检（任何改动后必须全绿） |
| `npm run verify:dist` | 构建产物校验（需先 `build:web`） |
| `npm run dist:mac` / `dist:win` / `dist:linux` | 打包当前平台安装包到 `release/` |

## 四、运行时可配置项

配置文件位于 `userData/settings.json`（macOS：`~/Library/Application Support/Claw Lite/settings.json`）。

| 项 | 默认 | 说明 |
|---|---|---|
| 端口 | `8799` | dsh web 监听端口，范围 1024–65535；越界或已被占用时自动换空闲端口 |
| 工作目录 | 用户主目录 | dsh 的工作目录 |
| DSH_HOME | `userData/dsh-home` | DSH 数据目录（留空则用默认） |
| DSH 版本 | 内置版本 | 选定后立即异步下载，完成即可切换启动，见 [[DSH-版本管理与热切换]] |
| 开机自启 | 关 | 应用启动后自动拉起 dsh |
| 打开方式 | 应用内窗口 | 或系统浏览器 |
