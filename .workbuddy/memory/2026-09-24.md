## 主窗口顶栏三缺陷修复（拖动区 / 交通灯重叠 / logo 纯色块）

- 根因：①`titleBarStyle: 'hiddenInset'` 隐藏原生标题栏后，`#topbar` 未声明 `-webkit-app-region: drag`，全窗口无拖动区；②顶栏用内边距撑高、无左侧安全区，系统原生交通灯压住品牌标题；③`.brand-mark` 是 CSS `radial-gradient` 占位块，不是真实图片。
- 修复：顶栏改固定高 `--topbar-h: 62px` 并整体作拖动区（按钮/状态胶囊显式 `no-drag`，否则点击被拖动行为吞掉）；`electron/main.cjs` 增 macOS 专用 `trafficLightPosition: { x: 16, y: 24 }`，渲染层 `body.is-mac` 下以 `--topbar-gutter: 84px` 预留左侧安全区（二者必须配套改）；logo 改 `<img src="./build/icon.png">` 复用打包同一份图标，Vite 输出 `dist/assets/icon-<hash>.png` 相对路径引用。
- **踩坑（验证手段受限）**：本机 `screencapture -R`（报 "could not create image from rect"）与 AX API（`osascript` 报 -1719 不允许辅助访问）均无系统权限，**无法截取含原生交通灯的整窗画面**。替代验证：Electron 内 `webContents.capturePage()` 取渲染层真实像素（PIL 核对 0–84pt 区域无亮像素=安全区为空、logo 区域为白底+橙色图形=真图标）+ `executeJavaScript` 读 `getBoundingClientRect` / `getComputedStyle().webkitAppRegion` 核对拖动区与几何；交通灯横向占用按系统标准 52pt（x=16→68 < 84）推算不重叠。
- 验证：`npm run build:web` 成功、`npm run check` 全绿；`docs/version/RELEASE-v1.0.md` 追加分节（不推进版本号），`AGENTS.md` §1「静态资源路径」与 §11「图片」同步品牌图标说明。
